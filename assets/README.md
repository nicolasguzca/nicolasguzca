# assets

- `profile.json`: the text on the right of the card. Edit it and push; the
  workflow rebuilds the SVGs. `{uptime}` is filled in from the account's age.
- `ascii-{dark,light}.txt` and `.tone`: the portrait, generated from the GitHub
  avatar by `tools/make_ascii.py` (needs Pillow, run by hand when the avatar
  changes).
